# 길냥이 식당

작은 밤, 따뜻한 한 끼. Phaser 3 + TypeScript + Vite로 만든 세로형 픽셀 힐링 경영 게임입니다. 현재 버전은 **0.2.0 · 비 오는 골목**입니다.

## 실행

Node.js 20.19+ 또는 22.12+에서:

```bash
npm ci
npm run dev
```

터미널에 표시되는 주소를 브라우저로 엽니다. 개발 서버의 Network 주소로 같은 Wi-Fi의 모바일에서도 접속할 수 있습니다.

```bash
npm run build
npm run preview
```

`dist/`가 정적 호스팅 배포 결과물입니다. GitHub Pages용 저장소 경로(`/gilnyang/`)는 `vite.config.ts`에서 설정했습니다. `main` 브랜치에 푸시하면 `.github/workflows/deploy.yml`이 빌드 후 Pages에 배포합니다. 처음 한 번 저장소의 **Settings → Pages → Source → GitHub Actions**를 선택하세요. 배포 주소는 `https://wanttogames.github.io/gilnyang/`입니다. 서버·DB·외부 API 없이 실행되며 입력과 진행 데이터는 서버로 전송하지 않습니다. 개발 서버의 핫 리로드 통신은 개발 환경에서만 사용됩니다.

단일 HTML 파일을 다시 만들려면 `npm run build` 후 `python scripts/export_standalone.py`를 실행하세요. 생성되는 `release/gilnyang-play.html`은 그래픽·글꼴·게임 코드가 들어 있는 단일 실행 파일입니다. 내려받아 Chrome/Edge 등으로 열면 플레이할 수 있습니다. 저장은 파일/사이트 주소와 브라우저별로 분리되므로 지속적인 플레이에는 같은 주소를 사용하세요. HTML 파일을 옮기거나 이름을 바꾸면 저장이 달라질 수 있습니다.

## 0.2.0 업데이트

- **맑음·비·눈**: 첫째 밤 맑음, 둘째 밤 비, 셋째 밤 눈. 넷째 밤부터 맑음 50% / 비 35% / 눈 15%로 정합니다.
- 날씨는 밤이 바뀔 때만 정하고 저장합니다. 새로고침으로 바뀌지 않습니다. 기존 저장의 진행 중인 밤은 맑음으로 이어갑니다.
- 빗방울·웅덩이·눈발·얇게 쌓인 눈을 표현합니다. 비 오는 밤은 합성 빗소리가 재생되며 소리 설정과 탭 숨김 상태를 따릅니다.
- 8명 모두 비 오는 밤 전용 주문·감사 대사를 가집니다. 취향을 맞춘 경우에는 취향 반응을 우선합니다.
- 비 오는 밤 **까망의 추첨 가중치 4**, 다른 손님과 맑음/눈의 까망은 1입니다. 실제 방문 확률은 방문 제한과 신규 손님 우선 방문에 따라 달라집니다.
- 한 밤에 같은 손님 최대 2회, 바로 연속해서 방문하지 않습니다. 새로운 손님이 열리는 밤에는 첫 방문을 보장합니다.

| 새 음식 | 해금 조건 | 조리 |
| --- | --- | --- |
| 계란 라면 | 까망 방문 3회 이상 **그리고** 친밀도 5 이상 | 면·국물·계란 → 추가 재료 선택 → 초록 구간에서 불 끄기 |
| 붕어빵 | 몽실 방문 3회 이상 **그리고** 친밀도 5 이상 | 반죽·팥 → 추가 재료 선택 → 초록 구간에서 뒤집기 → 다시 초록 구간에서 꺼내기 |

해금 조건은 서빙할 때 확인하며, 이미 조건을 달성한 기존 저장도 업데이트 후 바로 해금됩니다. 새 메뉴 안내는 확인할 때까지 저장되고 정산의 발견 목록에도 기록됩니다. 이후 까망은 계란 라면, 몽실은 붕어빵을 주문합니다. 해금 전에는 기존 어묵/우유를 주문합니다. 메뉴판에서 조건과 현재 진행도를 확인할 수 있습니다.

### 기존 프로젝트에 적용

`gilnyang-update-v0.2.zip`을 **현재 프로젝트 폴더 안에** 풀고 같은 이름의 파일을 덮어씁니다. `.git`과 기존 배포 설정은 유지됩니다. 기존 프로젝트 안에 `gilnyang` 폴더를 추가로 중첩하지 마세요.

PowerShell에서 현재 프로젝트 폴더로 이동한 후:

```powershell
npm ci
npm run build
git add .
git commit -m "Add weather and unlockable recipes"
git push origin main
```

기존 GitHub Pages Actions 설정으로 새 빌드가 배포됩니다. 브라우저의 같은 주소로 접속하면 기존 기록을 이어갑니다. 다른 주소/브라우저/단일 HTML 파일의 기록은 서로 공유되지 않습니다.

## 구현된 플레이

- 내부 해상도 720×1280, pixelArt, 세로형 화면, PC 마우스·모바일 터치
- 나비·두부·까망·몽실·콩이 5명의 첫 밤, 이후 밤마다 5회의 가중치 추첨 방문
- 등장 → 착석 → 주문 → 재료 선택 → 간단 요리 → 제공 → 대화 → 다음 손님
- 참치 주먹밥: 밥·참치·김 선택 후 2초 꾹 누르고 놓기
- 어묵: 재료 선택 후 초록 구간에서 건져내기
- 우유: 꾹 눌러 초록 구간까지 따르고 놓기
- 보통/맛있음/완벽 품질, 실패로 손님이 떠나지 않음
- 품질별 골드 +10/+12/+15, 친밀도 +1/+2/+3
- 발견한 취향을 맞추면 친밀도 +2, 방석 구매 시 +1
- 방문 5회&친밀도10, 10회&25, 15회&50의 짧은 이야기
- 손님 도감, 취향 공개, 이야기 다시 읽기, 미발견 실루엣
- 4번째 밤 보리, 7번째 밤 달이, 10번째 밤 호두 추가 방문: 손님 데이터 총 8명
- 매출·완벽 요리·친밀도·발견을 기록하는 밤 정산
- 등불·방석·냄비·간판 구매. 등불/방석/간판은 장면에 반영
- 생성형 앰비언트 멜로디·짧은 효과음, 음소거 설정 저장
- 주인공과 손님 눈 깜빡임·미세한 움직임, 김·불빛 애니메이션
- LocalStorage 자동 저장, 저장 실패 안내, 완료된 서빙 보상 중복 방지

한 밤의 시간은 강제하지 않습니다. 대화·도감·꾸미기를 둘러보며 느긋하게 플레이할 수 있습니다.

## 저장 방식

키: `alley-cat-diner-v1`을 그대로 유지합니다. 저장 형식은 v2이며 기존 v1 데이터를 읽어 자동 변환합니다. 골드·밤·식당 레벨·손님 방문/친밀도/이야기/취향·레시피·꾸미기·사운드 설정·진행 중인 밤 정산·현재 날씨·아직 확인하지 않은 레시피 해금 안내를 저장합니다. 브라우저 데이터 삭제 시 초기화됩니다. 식당 레벨은 누적 서빙 10회마다 1씩 오릅니다.

손님을 서빙한 시점에 보상과 방문 수를 함께 저장합니다. 요리 도중 새로고침하면 해당 손님의 주문부터 다시 시작합니다. 서빙 후 새로고침하면 다음 손님부터 이어집니다. 마지막 손님까지 서빙했으면 정산 화면을 복원합니다. 해금된 대화는 도감에서 다시 볼 수 있습니다.

## 구조와 에셋 교체

- `src/data/`: 손님·음식·재료·대화·꾸미기 데이터
- `src/systems/`: 저장·요리 판정·진행·친밀도·오디오
- `src/scenes/RestaurantScene.ts`: Phaser 식당 장면과 밤 상태 전이
- `src/scenes/CookingScene.ts`: 조리 UI와 마우스/터치 입력
- `src/scenes/CustomerBookScene.ts`, `ResultScene.ts`: 도감·정산 화면
- `src/ui/UI.ts`: 공통 UI 렌더링
- `src/scenes/BootScene.ts`: 48×48 절차적 캐릭터 텍스처 생성

조리/도감/정산은 별도 Phaser 렌더 장면을 띄우기보다 HTML UI 컨트롤러로 구현했습니다. 식당 장면을 계속 보여주면서 읽기 쉬운 글자와 터치 버튼을 제공합니다. 게임 로직은 데이터와 시스템 모듈로 분리되어 있습니다.

캐릭터를 PNG 에셋으로 교체하려면 BootScene의 절차적 생성 부분을 `this.load.image(id, ...)`로 바꾸고 동일한 텍스처 키(`chef`, `nabi`, `nabi-blink` 등)를 유지하세요. 요리와 도감의 CSS 아이콘은 `UI.food()` / `CustomerBookScene`에서 이미지로 교체할 수 있습니다. 배경은 `RestaurantScene.drawStreet()`에서 교체합니다. 외부 에셋 다운로드는 실행 시 필요하지 않습니다.

## GitHub에 연결

이 프로젝트의 원격 저장소는 `https://github.com/wanttogames/gilnyang.git`입니다. ZIP을 푼 다음 PowerShell에서 프로젝트 폴더로 이동해 GitHub 계정 인증을 완료하고 아래 명령을 실행하면 첫 커밋을 올릴 수 있습니다. GitHub CLI는 필요하지 않습니다. Git for Windows와 `git`이 필요합니다.

```powershell
cd .\gilnyang
git init -b main
git add .
git commit -m "Initial commit: Gilnyang MVP"
git remote add origin https://github.com/wanttogames/gilnyang.git
git push -u origin main
```

이 저장소가 비어 있지 않거나 이미 `origin`을 설정했다면 먼저 `git status`와 `git remote -v`를 확인한 뒤, 기존 커밋과 원격 내용을 확인하고 진행하세요.
